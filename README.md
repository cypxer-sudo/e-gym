# E-GYM — The Self-Development Platform
> **"BECOME UNREAL. TRAIN EVERY DIMENSION."**

A challenge-based personal development web application built directly from the **E-GYM Concept & Business Blueprint**.

---

## ⚡ Key Highlights & Architecture

- **Visual Direction**: Editorial, luxury institutional dark-mode aesthetic with charcoal (`#11141A`), obsidian (`#090B0E`), and restrained gold accents (`#D4AF37`).
- **Zero-Dependency Architecture**: Runs directly in modern browsers with HTML5, CSS3, ES6 JavaScript, Web Audio API synthesis, and LocalStorage persistence.
- **Brand Terminology**:
  - Member (User)
  - Personal HQ (Dashboard)
  - Departments (Features)

  - Training Programs & Protocols (Courses/Challenges)

  - Membership (Subscription)

---

## 🏛️ Core Platform Modules

### 1. Personal HQ (Member Command Center)
- **Today's Objectives**: Cross-challenge daily tasks with interactive checkboxes, dimension badges, and live progress calculations.
- **Active Challenges**: Live day countdowns (e.g. Day 13 of 75), visual progress bars, and one-click daily check-in triggers.
- **8-Dimension Radar**: Real-time geometric radar/spider chart mapping development across:
  - *Physical, Intellectual, Emotional, Psychological, Social, Financial, Professional, Creative*.
- **Live Metrics**: Consecutive streak tracker, Unreal Points equity, and objective completion rates.

### 2. The Challenge Arena (Signature Engine)
- **Flagship Protocols**:
  - *75-Day Discipline Protocol* (Mind + Body + Execution multi-domain standard)
  - *21-Day Reading Habit Mastery* (Mind)
  - *30-Day Strength & Mobility Foundation* (Body)
  - *14-Day Deep Work & Digital Boundaries* (Execution)
  - *30-Day Creator Sprint: Write & Publish* (Creation)
  - *30-Day Startup Validation Sprint* (Growth & Finance)
- **Protocol Inspection**: Full curriculum breakdown, daily standards, and safety/sustainability guidelines.
- **Enrollment Flow**: Instant protocol activation with automatic addition to daily objectives.

### 3. Departments
- **MIND (Reading Academy)**: Guided book roadmaps (*Atomic Habits, Deep Work, Meditations, Zero to One*), reading session logger, and key insight reflection capture.
- **BODY (Fitness & Health)**: Fundamental exercise library with form cues, sets/reps logger, and recovery state tracking.
- **EXECUTION (Productivity & Discipline)**: Interactive Pomodoro focus suite (25m standard, 50m flow, 5m reset), Web Audio gong chime, and digital boundary rules.
- **CREATION (Writing Studio)**: Distraction-free draft editor, live word counter, reflection prompts (*Anti-Goal Blueprint, First Principles Audit*), and portfolio storage.
- **GROWTH & CONNECTION**: High-leverage competence pathways and accountability cohort tracking.

### 4. Performance Record & Official Credentials
- Member dossier with verified milestones and earned institutional marks.
- **Official Protocol Credential Generator**: High-fidelity completion certificate with cryptographic verification ID and print/PDF support.

### 5. Institutional Membership
- Three-tier comparison: **Explorer** (Free), **Member** (₹349/month), and **Elite** (₹899/month) with interactive upgrade switching.

### 6. Acoustic Feedback & Vault Management
- **Acoustic Feedback**: Web Audio API-synthesized bell and chord harmonics (can be toggled on/off in the top bar).
- **Vault Management**: Export state to JSON backup, import existing backups, or reset baseline data.

## 🚀 How to Run

### Option 1: Double-Click Launcher (Windows)
Double-click `start.bat` in this folder. It will start the local server and automatically open the application in your default browser.

### Option 2: Python Command Line
```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python314\python.exe" server.py
```
Then visit `http://localhost:8000` in any web browser.

### Option 3: Direct File Open
Simply double-click `index.html` or open it directly in Google Chrome, Microsoft Edge, or Mozilla Firefox.
